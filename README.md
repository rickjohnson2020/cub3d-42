# cub3D

## Description

cub3D is a 3D graphical project based on **raycasting**, inspired by early first-person games such as *Wolfenstein 3D*.

The goal of this project is to render a 3D view of a maze from a first-person perspective using the MiniLibX graphics library and improve your skills in these areas: windows, colors, events, fill shapes.

Through this project, we implement real-time rendering, player movement, collision detection, texture mapping, and event handling while respecting strict memory management rules.

cub3D is a remarkable playground to explore the playful practical applications of mathematics without having to understand the specifics.

## Instructions

1. Clone this repository

```bash
git clone <Repository_URI> <dir_name>
```

2. Move into the project directory

```bash
cd <dir_name>
```

3. Build the project

```bash
make
```

4. Run the program

```bash
./cub3D <path_to_map_file>
```

## Controls

* `W`, `A`, `S`, `D`: Movethe player
* `←`, `→`: Rotate the camera
* `ESC` or window close button: Exit the program
